# Моё расписание

Ретро-сайт с расписанием, оценками и домашкой из «Сетевого города» (через [netschoolpy](https://git.dc09.xyz/ikrya/netschoolpy)).

- `server/` — FastAPI: вход, данные «Сетевого города», раздача собранного фронта. Зависимости — `pyproject.toml` + `uv.lock`.
- `web/` — фронт на Vite+ (`vp`) и Bun, TypeScript без фреймворков.

## Запуск

```bash
docker compose up -d --build
```

Сайт откроется на http://127.0.0.1:8000. Входы хранятся в томе `sessions` и переживают пересборку.

Мобильный режим — ключ в `.env` рядом с `compose.yaml` (или в окружении):

```bash
NETSCHOOL_MOBILE_CLIENT_SECRET=...
```

С телефона в той же Wi‑Fi: `SITE_HOST=0.0.0.0` в `.env`, затем http://netschool.local — имя объявляет
`scripts/mdns-name.sh [имя]` через Bonjour (например, LaunchAgent'ом при входе в систему).

Разработка фронта с горячей перезагрузкой — `bun install && bun run dev` в `web/`
(http://localhost:5173, `/api` проксируется на контейнер :8000). Проверки — `bun run check`.

## Вход

- **Логин и пароль** «Сетевого города».
- **Госуслуги** — логин и пароль Госуслуг; если включено подтверждение, сайт спросит код из SMS,
  «Макс» или приложения-аутентификатора (пуш в «Госключ» тоже ждёт).
- **QR-код Госуслуг** — сканируется приложением «Госуслуги»; с телефона — кнопкой «Открыть Госуслуги».

Школа выбирается своим списком: поиск по словам в любом порядке и по номеру, обычные школы выше
детсадов и отделений, недавние — сверху. Список организаций региона кэшируется на сутки.

## Откуда берутся данные

1. **Мобильный API** — если задан `NETSCHOOL_MOBILE_CLIENT_SECRET` (ключ приложения parent-mobile,
   с библиотекой не поставляется). Полный дневник: кабинеты, учителя, оценки, домашка, без лимитов.
2. **Веб-дневник** `student/diary`.
3. **Если дневник пустой** (так бывает на некоторых серверах): расписание `schedule/classmeetings`,
   оценки — отчёт StudentTotal (раз в 10 минут), домашка — отчёт StudentGrades по клику на урок
   (кэш 30 минут). «Сетевой город» ограничивает число отчётов на пользователя, поэтому они ленивые.

## Кэш

- Ассеты из `web/dist/assets` с хэшем в имени — `immutable` на год, `index.html` — `no-cache`.
- Недели в браузере — stale-while-revalidate (память + sessionStorage, свежесть 60 с),
  следующая неделя подгружается в простое.
- Входы хранятся в `/data/sessions.json` в томе контейнера (права 600), чтобы перезапуск не разлогинивал.
